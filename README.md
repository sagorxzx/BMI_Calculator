# BMI Calculator

A clean, modern, and responsive Body Mass Index (BMI) calculator built with HTML, CSS, and JavaScript. It provides instant BMI calculations based on height (feet/inches) and weight (kg) inputs, along with clear category feedback and a visual reference guide.

## ✨ Features

- **Instant BMI Calculation** – Get your BMI and category with one click or by pressing Enter.
- **Clean & Modern UI** – Glass-morphism design with smooth animations and a professional look.
- **Fully Responsive** – Optimized for desktop, tablet, and mobile devices.
- **Visual Feedback** – The result card changes color based on your BMI category (Underweight, Normal, Overweight, Obese).
- **BMI Reference Guide** – A beautifully designed card-based reference table for quick comparison.
- **No Pre-Calculation** – Opens with empty inputs, so you always start fresh.

## 🛠️ Technologies Used

- **HTML5** – Semantic structure
- **CSS3** – Custom styling with flexbox, grid, and responsive design
- **JavaScript (Vanilla)** – DOM manipulation, event handling, and BMI logic
- **Font Awesome** – Icons for enhanced visual appeal
